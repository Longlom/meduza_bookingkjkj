# Инструкция для администратора / hostess — Meduza

Простая инструкция: как настроить QR-коды на столах, фото сотрудников и смену в Google Таблице.  
**Перед печатью QR-кодов** уточните у менеджера адрес сайта Meduza (например `https://meduza-nt.com`).

## Как это работает (коротко)

1. Гость сканирует **QR-код на столе** → открывается страница вызова персонала.
2. На странице **всегда** есть кнопки **«Кто свободен»** (официант / кальянщик) — может прийти любой свободный сотрудник.
3. Если в таблице у сотрудника стоит **enabled = TRUE**, гость additionally видит **карточку с именем** и может позвать конкретного человека.
4. Изменения в таблице появляются на сайте примерно через **1 минуту**. Перезапуск сайта **не нужен**.

## 1. QR-код для каждого стола

### Что должно быть в ссылке

Для **стола № 1**:
```
https://meduza-nt.com/call?table=1
```

Для **стола № 12**:
```
https://meduza-nt.com/call?table=12
```

Замените `ВАШ-САЙТ` на реальный адрес (без пробелов).  
Номер стола — только **цифры и латинские буквы** (например: `1`, `12`, `vip3`).

### Как сделать QR-код (на телефоне или компьютере)

**Способ A — сайт (проще всего)**

1. Откройте в браузере: [qr-code-generator.com](https://www.qr-code-generator.com/) или [goqr.me](https://goqr.me/)
2. Выберите тип **URL** / **Ссылка**
3. Вставьте ссылку, например: `https://meduza-nt.com/call?table=5`
4. Нажмите **Create QR Code** / **Создать**
5. Скачайте картинку (PNG)
6. Повторите для каждого стола (меняйте только номер: `table=1`, `table=2`, …)

**Способ B — приложение на телефоне**

В App Store / Google Play найдите «QR code generator», создайте код из той же ссылки.

### Печать и установка

1. Подпишите код: **«Стол 5»** (чтобы не перепутать)
2. Распечатайте и заламинируйте (или используйте пластиковую подставку)
3. Положите на стол
4. **Проверка:** отсканируйте камерой телефона → должна открыться страница с текстом **«Стол 5»** (или Table 5)

### Важно

- Делайте **отдельный QR на каждый стол** — номер в ссылке должен совпадать со столом.
- Если адрес сайта когда-нибудь сменится — QR-коды нужно будет сделать заново (спросите менеджера).

## 2. Фото сотрудника в Google Drive

Фото хранятся в общей папке:  
[stff_images](https://drive.google.com/drive/folders/1HRreA28t0_rWbe-AWCeL-QSaWO0FJq4m?usp=sharing)

### Загрузить новое фото

1. Откройте папку **stff_images** на телефоне (приложение Google Drive) или в браузере.
2. Нажмите **+** → **Загрузить** → выберите фото с телефона.
3. Назовите файл понятно, например: `anna.jpg`, `mike.jpg`.

### Сделать фото доступным для сайта (обязательно!)

Ссылка на **папку** не подходит. Нужна ссылка на **каждый файл**:

1. Откройте **само фото** (не папку).
2. Нажмите **Поделиться** (Share).
3. **Общий доступ** → **Все, у кого есть ссылка** → **Читатель** (Viewer).
4. Нажмите **Копировать ссылку**.

Ссылка должна выглядеть так:
```
https://drive.google.com/file/d/XXXXXXXX/view?usp=sharing
```

**Не используйте** ссылку вида `.../drive/folders/...` — это папка, сайт фото не покажет.

### Вставить ссылку в таблицу

1. Откройте [таблицу смены](https://docs.google.com/spreadsheets/d/16-16OM3a_OHSVCnYS0M3Cq0RJx54pxjQDpCcaVn2Wr4/edit?usp=sharing).
2. Найдите строку сотрудника (например Anna).
3. В колонку **photoUrl** вставьте скопированную ссылку на **файл**.
4. Если фото нет — оставьте **photoUrl пустым** (сайт покажет цветной аватар с буквами).

### Проверка фото

Через 1–2 минуты откройте страницу вызова (`/call?table=1`) — у сотрудника с `enabled=TRUE` должно появиться фото.  
Если фото пустое — проверьте, что файл открыт **«Все, у кого есть ссылка»**.

## 3. Google Таблица — кто на смене

Таблица: [meduza-stff-shift](https://docs.google.com/spreadsheets/d/16-16OM3a_OHSVCnYS0M3Cq0RJx54pxjQDpCcaVn2Wr4/edit?usp=sharing)

### Колонки (первая строка — не трогать!)

| Колонка | Что писать | Пример |
|---------|------------|--------|
| **id** | Короткий код латиницей (можно не менять) | `anna` |
| **name** | Имя на экране у гостя | `Anna` |
| **role** | `waiter` (официант) или `hookah` (кальянщик) | `waiter` |
| **photoUrl** | Ссылка на **файл** в Google Drive (см. раздел 2) | `https://drive.google.com/file/d/...` |
| **enabled** | `TRUE` — показывать карточку с именем; `FALSE` — скрыть | `TRUE` |

Также можно писать: **да** вместо TRUE (для «на смене»).

### Пример правильных строк

| id | name | role | photoUrl | enabled |
|----|------|------|----------|---------|
| anna | Anna | waiter | https://drive.google.com/file/d/1Vo6i94.../view?usp=sharing | TRUE |
| bob | Bob | waiter | | FALSE |
| mike | Mike | hookah | | TRUE |

### Частые ошибки — не делайте так!

| Ошибка | Почему плохо |
|--------|----------------|
| `TRUE` / `FALSE` в колонке **photoUrl** | Ссылка на фото сломается |
| Ссылка на **папку** Drive в photoUrl | Фото не загрузится |
| Удалили заголовки в строке 1 | Таблица перестанет читаться |
| `официант` в role вместо `waiter` | Можно: `waiter`, `hookah`, `официант`, `кальянщик` — лучше придерживаться `waiter` / `hookah` |

### Ежедневная смена (каждый вечер)

1. Откройте таблицу в приложении **Google Sheets** на телефоне.
2. Для каждого сотрудника, кто **работает сегодня**, поставьте **enabled = TRUE**.
3. Кто **не работает** — **enabled = FALSE**.
4. Сохранение происходит автоматически.

**Не обязательно** включать кого-то в TRUE: гости всё равно могут нажать **«Кто свободен»** и позвать любого официанта или кальянщика.

### Добавить нового сотрудника

1. Добавьте **новую строку** внизу (не вставляйте строку между данными, если не уверены).
2. Заполните: **id**, **name**, **role**, **photoUrl** (если есть), **enabled**.
3. Загрузите фото в [папку stff_images](https://drive.google.com/drive/folders/1HRreA28t0_rWbe-AWCeL-QSaWO0FJq4m?usp=sharing) и вставьте ссылку на файл.

## Чек-лист перед открытием

- [ ] В таблице **enabled = TRUE** у тех, кто на смене (если нужны именные карточки)
- [ ] QR-коды на всех столах, подписаны номером стола
- [ ] Один QR проверен сканированием с телефона
- [ ] Фото (если есть) открыты «Все, у кого есть ссылка»

## Если что-то не работает

| Проблема | Что проверить |
|----------|----------------|
| QR открывает не ту страницу | Номер в ссылке `table=` совпадает со столом? |
| Нет фото у сотрудника | В **photoUrl** ссылка на **файл**, не папку; доступ «Все, у кого есть ссылка» |
| Сотрудник не появляется на сайте | **enabled = TRUE**? Имя и **role** заполнены? |
| Изменения не видны | Подождите 1–2 минуты; обновите страницу |
| Гость видит только «Кто свободен» | Это нормально, если у всех **enabled = FALSE** |

При технических проблемах обратитесь к менеджеру / IT.
